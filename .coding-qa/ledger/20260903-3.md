## Brief（要做什么）

统一文件系统 skill 的停用、重装和删除语义：Windows 始终使用字面路径；POSIX 目标冲突必须失败，不得把 `mv -n` 未移动当成成功；停用/重装在 index 原子提交失败时反向移动回滚。

## 断言清单

- [x] Windows mkdir/move/remove 都不解释 `[]*?` 等通配符。
- [x] POSIX move 在目标已存在时非零退出，且不覆盖原目标。
- [x] 停用在“目录已移入 trash，index 提交失败”时把目录移回原位。
- [x] 重装在“目录已恢复，index 提交失败”时把目录退回 trash。
- [x] 回滚失败时同时报告原错误与回滚错误，不伪装成功。
- [ ] 完整测试、typecheck、build、pack 与双轴 review 通过（四门禁已通过，review 待执行）。

## 公开测试缝

- `mkdirCommand` / `moveNoClobberCommand` / `removeRecursiveCommand` 纯函数。
- `/api/skill-manager` 的 `uninstall` / `reinstall` 路由。

## 边界（不做什么）

- 不修改临时 skill 会话隔离。
- 不改变 trash 目录位置、索引 schema 或 UI 文案。
- 不迁移当前 DSH profile，不重启 DSH。
- 跨文件系统不降级为非原子 copy-delete；在改动源文件前安全拒绝并返回错误。
